# 🗝️ Vocabulary Vault

Modern, koyu temalı ve göz yormayan bir kelime defteri uygulaması. İngilizce kelimelerini buraya topla, anlamlarını elle gir veya otomatik çevir, her kelime için örnek cümle üret.

## ✨ Özellikler

- 📱 **Tamamen responsive** — telefon, tablet ve masaüstünde sorunsuz çalışır
- 🌙 **Modern koyu tema** — göz yormayan, geceleyin rahat görülebilir arayüz
- ➕ **Kelime ekle** — İngilizce kelime + Türkçe anlamı (elle veya otomatik çeviri ile)
- 🔁 **Otomatik çeviri** — tek tıkla İngilizceden Türkçeye çeviri
- 📝 **Örnek cümle üretici** — her kelime için anlamlı örnek cümle oluştur
- 🔍 **Arama ve filtre** — kelimelerinde arama yapabilirsin
- 💾 **Yerel depolama** — kelimeler tarayıcında saklanır, sayfa yenilense de kalır
- ⚡ **Sıfır kurulum** — tek HTML dosyası, herhangi bir tarayıcıda açılabilir

## 🚀 Kullanım

1. `index.html` dosyasını herhangi bir modern web tarayıcısında aç.
2. "Yeni Kelime Ekle" formunda İngilizce kelimeyi yaz.
3. Anlamını elle gir ya da **🔁 Otomatik Çevir** butonuna bas.
4. **📝 Örnek Cümle Üret** butonuna basarak örnek cümle al.
5. Kaydet butonuna basarak kelimeyi vault'ına ekle.

## 🛠️ Teknolojiler

- HTML5
- CSS3 (Glassmorphism, responsive grid, dark mode)
- Vanilla JavaScript (localStorage, Fetch API)
- Harici kütüphane yok
